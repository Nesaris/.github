# Nesaris Network

Self-hosted network tools — mapping, monitoring and securing your own LAN.

Website: https://nesaris.github.io

| Project | Description |
|---|---|
| [Vigie](https://github.com/Nesaris/Vigie) | Defensive network audit and monitoring tool for your own LAN. |
| [Synapse](https://github.com/Nesaris/Synapse) | Self-hosted memory service for AI agents (L0–L3 cascade, MCP server). |
| [Relay](https://github.com/Nesaris/Relay) | Zero-dependency Node.js edge and control layer for the Nesaris Hub. |
| [ProxLab](https://github.com/Nesaris/ProxLab) | Web interface to manage Proxmox VE: VMs, containers and consoles. |
| [NexArc](https://github.com/Nesaris/NexArc) | Self-hosted IT fleet monitoring: agents report inventory, security posture and metrics; remote tasks, consoles, Wake-on-LAN. |
| [Nesmail](https://github.com/Nesaris/Nesmail) | Self-hosted alert inbox that turns alert emails into tracked tickets. |
| [MapMyLAN](https://github.com/Nesaris/MapMyLAN) | Self-hosted network monitoring: device discovery, topology mapping, vulnerability detection and threat blocking. |
| [Hub](https://github.com/Nesaris/Hub) | Nesaris Hub — central dashboard that installs and manages your self-hosted services as extensions. |
| [Dialekt](https://github.com/Nesaris/Dialekt) | Local AI (Ollama) vs Claude duels, scored by a deterministic judge. |
